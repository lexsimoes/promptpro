## Configuration, privacy and implementation boundaries

`CLASS_CODES_JSON` entries contain exact code, expiry with timezone (for example `2026-12-31T23:59:59-03:00`), positive attempt limit and active flag. Owner creates, renews or disables entries through environment configuration and redeploy; never expose a public `VITE_` secret. Class link: `https://getprompt.pro/#t=<percent-encoded-code>`. Browser holds the decoded code in memory and sends it in JSON POST to `/api/access` and every `/api/generate`. Check validity/expiry before LLM; only generation consumes the best-effort counter. Fragments do not enter HTTP targets or Referer, but JavaScript/history can expose them: no analytics or session replay. [Fragment](https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Fragment), [Referer](https://www.w3.org/TR/referrer-policy/#strip-url).

Server rejects blank or >2,000-character ideas before LLM. Output: **1,500 tokens**, temperature **0.2**, thinking off; measured v2 mean **373.75**, maximum **487** tokens. Full report/raw results stay local-only at prototype/model-choice/results/REPORT.md; [committed report](../../prototype/model-choice/REPORT.md) and [metrics](../../prototype/model-choice/metrics.csv) provide reviewable evidence. Proposed upstream timeout 20 seconds, browser wait 25 seconds, no automatic retry and one in-flight submission. Current adapter defaults to 120 seconds; later additive configuration needs authorization. Manual retries/new versions may cost again; preserve the idea on failure. Mock-only isolated e2e uses `turma-e2e-limite`, one attempt per process, without claiming a distributed guarantee.

Netlify logs request URL/query, IP and metadata plus explicit function logs; documentation does **not** establish that request bodies are never captured. Launch verification must inspect sentinel requests, platform/error logs and tracing settings. Idea only in POST body; no payload/code/header/raw-error logging, browser persistence or response caching. Same-origin API with exact Origin validation, server-side class validation, generic errors and function response headers: no-store, nosniff, no-referrer and CSP restricted to self-hosted assets. Free variables reach builds; Functions-only scope requires Pro. Trusted builds and artifact inspection remain necessary. [Observability](https://docs.netlify.com/manage/monitoring/observability/overview/), [function logs](https://docs.netlify.com/build/functions/logs/), [variable scope](https://docs.netlify.com/build/functions/environment-variables/), [headers](https://docs.netlify.com/manage/routing/headers/).
